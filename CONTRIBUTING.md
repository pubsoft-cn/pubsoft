# Contributing

This repository does **not** accept pull requests — external PRs are closed automatically.

Patches are accepted by email only: **pubsoft@gmail.com**

- `git format-patch` output or a plain unified diff against `main` both work.
- One logical change per patch, with the why in the commit message.
- Report bugs or propose changes first by email before sending large patches.

Security issues: see [SECURITY.md](SECURITY.md).
