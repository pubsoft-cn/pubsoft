# Security Policy

**English** | [简体中文](SECURITY.zh-CN.md)

## Reporting a Vulnerability

Please report security vulnerabilities privately to **pubsoft@gmail.com** rather
than opening a public issue. Include a description of the issue, affected
packages/versions, and steps to reproduce.

We will acknowledge receipt as soon as possible. Please allow reasonable time
for investigation and a fix before public disclosure.

## Scope

This policy covers the `PubSoft.*` packages published from this repository.
Security issues in host applications consuming these packages are the
responsibility of their respective maintainers.
